Zugänge
Anmeldekonten für das Dashboard – getrennt von der Einsatzplanung unter „Mitarbeiter“
So legst du einen Zugang an

Das Anmeldekonto selbst entsteht in der Firebase-Konsole – aus Sicherheitsgründen kann das Dashboard keine Passwörter vergeben.

  1. Konto anlegen
    Firebase-Konsole → Authentication → Users → Add user. E-Mail und ein Passwort vergeben.
  2. UID kopieren
    Steht in derselben Liste ganz rechts. Eine lange Zeichenfolge, keine E-Mail-Adresse.
  3. Hier eintragen
    UID einfügen, Namen und Rolle wählen, speichern. Erst dann kommt der Zugang hinein.
